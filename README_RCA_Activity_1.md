# RCA Activity 1 — Multiple Linear Regression

## Project
**House Value Prediction using the California Housing Dataset**

This project implements single-feature and multiple linear regression to predict median California house values. It includes a small-sample manual least-squares calculation, library verification, test-set evaluation, residual analysis, multicollinearity checks using VIF, and a new prediction.

## Dataset
- **Name:** California Housing
- **Source:** https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html
- **Loader:** `sklearn.datasets.fetch_california_housing`
- **Target:** `MedHouseVal`, measured in units of $100,000
- **Predictors:** `MedInc`, `HouseAge`, `AveRooms`, `AveBedrms`, `Population`, `AveOccup`, `Latitude`, `Longitude`

The dataset loader downloads the data when first run, so an internet connection may be required.

## Files
- `RCA_Activity_1_Multiple_Linear_Regression.ipynb` — complete executable notebook.

## How to run
1. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
2. Run all cells from top to bottom.
3. Review the printed outputs and plots.
4. Complete the decision log and conclusion using the actual results from your run.
5. Do not copy or invent metric values; report the outputs generated by your execution.

## Analysis included
1. Dataset inspection and cleaning
2. Pair plot and correlation heatmap
3. Manual normal-equation calculation using two predictors
4. Verification with Scikit-learn
5. Single-feature baseline and multiple-feature regression
6. MAE, MSE, RMSE, R² and adjusted R²
7. Actual-versus-predicted and residual plots
8. VIF multicollinearity check
9. Standardised coefficients
10. New example prediction and training-range check
